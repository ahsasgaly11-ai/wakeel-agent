# وكيل (Wakeel) 2.0 — وكيل ذكي يدير هاتف أندرويد

تطبيق أندرويد شخصي يرى الشاشة ويتحكم بالتطبيقات عبر خدمة إمكانية الوصول، وينفّذ المهام التي تكتبها أو تقولها بأقل استهلاك ممكن لواجهة الذكاء الاصطناعي.

## كيف ينفّذ المهمة (من الأرخص إلى الأغلى)
1. **مهارة متعلَّمة** — مهمة نجحت سابقاً تُعاد محلياً، حتى بقيم مختلفة («أرسل لـ {الاسم}: {الرسالة}»). بلا أي طلب.
2. **أمر محلي** — إعدادات الهاتف (30 صفحة)، تشغيل وإيقاف الواي فاي والبلوتوث، بحث مباشر في يوتيوب وجوجل والخرائط والمتجر، منبه، مؤقت، كشاف، صوت، وسائط، معلومات البطارية والتخزين والذاكرة والشبكة، تشخيص الهاتف. بلا أي طلب.
3. **خطة كاملة في طلب واحد** — يُعطى النموذج ثلاثة مصادر معرفة فيرسم المسار كله عبر عدة شاشات دفعة واحدة:
   - **دليل مدمج** لتخطيط نحو 35 فئة تطبيقات (تواصل، مراسلة، تداول، متصفح، إعدادات سامسونج…) مع الروابط المباشرة.
   - **خريطة يتعلّمها من هاتفك**: صفحات كل تطبيق والضغطات التي تنقل بينها، تُبنى مجاناً أثناء العمل، أو بالاستكشاف الآمن، أو (اختيارياً) بمراقبة استخدامك.
   - **خطط تشخيص** للتخزين والبطارية والبطء والحرارة والشبكة والإشعارات، مع قراءات الجهاز الحية.
4. **التعلّم** — بعد النجاح تُحفظ المهمة مهارةً، وتُحفظ ملاحظات عن التطبيق.

## الأمان
- ثلاث صلاحيات لكل تطبيق: **مسموح**، **قراءة فقط** (تطبيقات التداول افتراضياً: يحلّل ولا يشتري ولا يبيع ولا يحوّل)، **محجوب** (البنوك والمحافظ ومديرو كلمات المرور).
- تأكيد قبل الإرسال والدفع والحذف والتثبيت. لا يكتب كلمات المرور. لا يضغط أيقونات الشاشة الرئيسية.
- حدود ميزانية للمهمة ولليوم، وحارس يوقف التكرار، وزر إيقاف فوري.
- المفتاح مشفّر في Android Keystore. كل ما يتعلّمه يبقى على الجهاز.

## البنية
```
core/     الإعدادات، التخزين المشفّر، قراءات الجهاز، النماذج
service/  خدمة إمكانية الوصول، قارئ الشاشة، الفقاعة العائمة، التعلّم بالمراقبة
agent/    المحرّك، الأوامر المحلية، قاعدة المعرفة، خرائط التطبيقات، المهارات، الأمان
llm/      عميل Claude، عميل متوافق مع OpenAI، التعليمات
ui/       واجهات Compose (القيادة، المعرفة، السجل، الإعدادات)
```
