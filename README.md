# وكيل (Wakeel) — وكيل ذكي للتحكم بهاتف أندرويد

تطبيق أندرويد يرى الشاشة ويتحكم بالتطبيقات عبر خدمة إمكانية الوصول، ويستخدم نموذج ذكاء اصطناعي (Claude افتراضياً) لتنفيذ المهام التي تكتبها أو تقولها.

## المزايا
- **تحكم كامل:** نقر، ضغط مطوّل، كتابة، إدخال، تمرير، رجوع، الرئيسية، الإشعارات، فتح التطبيقات، لقطات شاشة.
- **توفير الاستهلاك:**
  - موجّه محلي ينفّذ الأوامر الشائعة دون أي طلب API (فتح تطبيق، منبه، مؤقت، بحث، اتصال، واي فاي…).
  - إرسال نص الشاشة المضغوط بدل الصورة، والصورة مصغّرة فقط عند الحاجة.
  - التخزين المؤقت للتعليمات (Prompt Caching).
  - عدة أفعال في ردّ واحد.
  - نموذج رخيص (Haiku 5.5) افتراضياً، والرفع إلى Sonnet عند التعثّر فقط.
  - حفظ مسارات المهام الناجحة وإعادة تشغيلها محلياً.
  - حدود ميزانية لكل مهمة ويومياً، وعدّاد تكلفة.
- **الأمان:** تأكيد قبل الإرسال والدفع والحذف، وحجب تطبيقات البنوك والمحافظ تلقائياً، وقائمة بيضاء اختيارية، ورفض الكتابة في حقول كلمات المرور، والمفتاح يُحفظ مشفّراً في Android Keystore، وزر إيقاف فوري.
- **الواجهة:** عربية بالكامل، ومحتواها من اليمين لليسار، بتصميم Material 3 ووضع داكن، مع فقاعة عائمة فوق كل التطبيقات، وإدخال صوتي، وسجل مفصّل لكل مهمة.

## التثبيت
1. حمّل أحدث ملف APK من صفحة **Releases**.
2. افتحه واسمح بالتثبيت من هذا المصدر.
3. افتح «وكيل»، ثم اضغط «فتح إعدادات إمكانية الوصول»، وشغّل خدمة «وكيل».
   - إن ظهرت رسالة «إعداد محظور» (أندرويد 13 فأعلى): معلومات التطبيق ← ⋮ ← «السماح بالإعدادات المحظورة»، ثم أعد التفعيل.
4. من **الإعدادات** الصق مفتاح API، ثم اضغط «اختبار الاتصال».

## البناء
يُبنى تلقائياً عبر GitHub Actions عند كل دفع إلى الفرع `main`، ويُنشر في Releases.
البناء محلياً: `gradle :app:assembleRelease` (يتطلب Android SDK 35 وJDK 17).

## البنية
```
core/     الإعدادات، والتخزين المشفّر، والنماذج
service/  خدمة إمكانية الوصول، وقارئ الشاشة، والفقاعة العائمة
agent/    المحرّك، والموجّه المحلي، والأمان، والمسارات المحفوظة، والسجل
llm/      عميل Claude، وعميل متوافق مع OpenAI، والتعليمات
ui/       واجهات Compose
```
